# Security reporting

Coupure is an experimental custodial **regtest** system. Do not deposit real Bitcoin or reuse real-wallet seeds.

Report vulnerabilities privately through the repository's GitHub **Security → Report a vulnerability** action if enabled. If unavailable, contact the maintainer through the GitHub profile and request a private reporting channel; do not post seeds, bearer tokens, macaroons or payment details in public issues.

Include the affected revision, reproduction steps on regtest and the expected/observed behavior. The detailed trust boundaries and remaining risks are in [docs/THREAT_MODEL.md](docs/THREAT_MODEL.md). There is no independent security audit or guaranteed response SLA.
