# AI use

Coupure is built by one person working with an AI coding agent (Claude Code). This file says what the
agent produced, what a human checked, and how. It is updated at every phase gate.

| Area | Generated by the agent | How it is verified |
|---|---|---|
| G0 infrastructure: `infra/compose.yaml`, `infra/uplink/relay.py`, `infra/postgres/init.sh`, `scripts/*.sh` | All code and config | Runs end to end against real bitcoind, LND and Nutshell: `make g0` (mint quote paid over Lightning) and `scripts/partition_check.sh` (Lightning fails on cut, recovers on restore). Read-only DB role checked by attempting a write. |
| G1 box daemon `box/coupured/` (island monitor, ledger, receipts, LND client, API) and SIMULATED faucet | All code and tests | 13 pytest tests incl. hypothesis tamper detection; the E2E drives every endpoint against the real stack. |
| G1 wallet `wallet/` (engine, vault, i18n catalogues, Svelte screens, Playwright E2E) | All code and tests; French and English copy; **Wolof is a machine draft, every line tagged `[wo-review]`** | `svelte-check` 0 errors, vitest + fast-check (BIP-39 test vector, vault tamper/wrong PIN, money properties), and `e2e/demo.spec.ts` passing twice in a row against real bitcoind/LND/Nutshell with a real partition. |
| G1 infra: Caddy image, creds baking, `miner` | All config | Same E2E; the stale-tip lnd hang was diagnosed from lnd logs, not guessed. |
| `docs/VERSIONS.md` | Text | Every version and env var was read from the release page, registry, or the source at the pinned tag, not from model memory. |

## Rules the agent works under
- No API is used before the installed version's source is read (`docs/VERSIONS.md`).
- No fakes in the happy path. Anything simulated is labelled `SIMULATED:`.
- Wolof strings are machine drafts until a native speaker reviews them; each carries `[wo-review]`.
- Human review status per gate is recorded below.
